Ray

Ray2D and Ray3D represent a parametric ray x + t * n, t ≥ 0. Ray geometry powers the laser propagation examples in the JuliaAstroSim ecosystem and the Finite-Difference Time-Domain electromagnetics solver. Each ray carries an origin (x) and a direction (n); the 2D version additionally stores the azimuth angle theta for cheap rotation / coordinate conversions.

Types

The ray type hierarchy is AbstractGeometryType{T} > AbstractRay{T} > AbstractRay{2D,3D}{T} > Ray{2D}. See Library reference for the concrete structs.

Intersections and reflections

See Library reference for intersect / reflect on the ray family (and the generic reflect(v, n) vector mirror).

The package-level reflect(vec, n) mirrors a vector vec about a unit normal n: vec − 2·(n · vec) · n.

Example

julia> using PhysicalMeshes
julia> using PhysicalParticles
julia> ray = Ray2D(PVector2D(0.0, 0.5), PVector2D(1.0, 0.0))Ray2D{Float64}(PVector2D{Float64}(0.0, 0.5), PVector2D{Float64}(1.0, 0.0), 0.0)
julia> line = Line2D(PVector2D(0.5, 0.0), PVector2D(0.5, 1.0))Line2D{Float64}(PVector2D{Float64}(0.5, 0.0), PVector2D{Float64}(0.5, 1.0))
julia> hit, point = intersect(ray, line)(true, PVector2D{Float64}(0.5, 0.5))
julia> hittrue
julia> pointPVector2D{Float64}(0.5, 0.5)
julia> reflected = reflect(ray, line)Ray2D{Float64}(PVector2D{Float64}(0.5, 0.5), PVector2D{Float64}(-1.0, 0.0), 3.141592653589793)
julia> reflectedRay2D{Float64}(PVector2D{Float64}(0.5, 0.5), PVector2D{Float64}(-1.0, 0.0), 3.141592653589793)
julia> # 3D ray-plane
       r3 = Ray3D(PVector(0.0, 0.0, 0.0), PVector(1.0, 1.0, -1.0))Ray3D{Float64}(PVector{Float64}(0.0, 0.0, 0.0), PVector{Float64}(1.0, 1.0, -1.0))
julia> pl = Plane(PVector(1.0, 0.0, 0.0), PVector(0.0, 1.0, 0.0), PVector(0.0, 0.0, 1.0))Plane{Float64}(PVector{Float64}(1.0, 0.0, 0.0), PVector{Float64}(0.0, 1.0, 0.0), PVector{Float64}(0.0, 0.0, 1.0))
julia> hit3, p3 = intersect(r3, pl)(true, PVector{Float64}(1.0, 1.0, -1.0))
julia> hit3true
julia> p3PVector{Float64}(1.0, 1.0, -1.0)

Properties and conventions

  • Ray2D zero / non-zero checks are dispatching on the direction vector: zero(::Ray2D) produces a degenerate ray with both origin and direction zeroed and iszero(::Ray2D) is true exactly when iszero(r.n). The same convention holds for Ray3D.
  • intersect(::Ray2D, ::Line2D) returns (false, PVector2D()) for parallel rays and degenerate segments (a == b); otherwise it returns (true, intersection_point).
  • intersect(::Ray3D, ::Plane) treats the plane normal as the bisector: when dot(ray.n, N) ≈ 0 the ray is parallel to the plane and we return (false, PVector(0, 0, 0)). A parallel-but-ill-defined ray is signalled by the 1e-6 * unit(denom) tolerance rather than exact zero.
  • The azimuth angle theta stored in Ray2D is automatically computed from the direction vector at construction; mutating r.n does not update it.
