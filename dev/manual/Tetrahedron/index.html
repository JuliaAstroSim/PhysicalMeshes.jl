Tetrahedron

Tetrahedron{T} is the simplest 3D simplex: four vertices and the corresponding circumcenter / insphere / volume / orientation machinery.

Types

The tetrahedron type hierarchy is AbstractGeometryType{T} > AbstractTetrahedron{T} > Tetrahedron{T}. See Library reference for the concrete struct.

Arithmetic, orientation, circumcenter, insphere

See Library reference for centroid, circumcenter, insphere, orient, volume, orientation on the tetrahedron family.

Example

julia> using PhysicalMeshes
julia> using PhysicalParticles
julia> t = Tetrahedron(
           PVector(1.0, 0.0, 1.0),
           PVector(1.0, 1.0, 0.0),
           PVector(0.0, 1.0, 1.0),
           PVector(1.0, 1.0, 1.0)
       )Tetrahedron{Float64}(PVector{Float64}(1.0, 0.0, 1.0), PVector{Float64}(1.0, 1.0, 0.0), PVector{Float64}(0.0, 1.0, 1.0), PVector{Float64}(1.0, 1.0, 1.0))
julia> centroid(t)PVector{Float64}(0.75, 0.75, 0.75)
julia> circumcenter(t)PVector{Float64}(0.5, 0.5, 0.5)
julia> insphere(t, PVector(0.5, 0.5, 0.5))Interior()
julia> insphere(t, PVector())OnEdge()
julia> insphere(t, PVector(2.0, 0.0, 0.0))Exterior()
julia> PhysicalMeshes.volume(t)0.16666666666666666
julia> orientation(t)PositivelyOriented()

Properties and conventions

  • volume(::Tetrahedron) returns abs(orient) / 6, where orient is the signed 6×volume of the tetrahedron.
  • insphere(...) uses the Shewchuk kernel and rejects near-coplanar configurations by combining the kernel value with the (orientation-aware) determinant of the four vertices. The return value is one of Interior(), Exterior(), or OnEdge().
  • circumcenter(::Tetrahedron) throws ArgumentError("Coplanar points: no unique circumcenter") for the degenerate 4-coplanar-points case.
