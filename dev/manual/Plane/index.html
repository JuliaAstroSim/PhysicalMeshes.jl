Plane

A Plane{T} is defined by three PVector{T} points (a, b, c). The geometric structure is the triangle / disk that lies on the unique plane through those points. Planes are used by Ray for ray-plane intersection and by the Polygon constructors to check coplanarity.

Type

Arithmetic and projection

See Library reference for the normal(::Point, ::Point, ::Point), normal(::Plane), and distance(::AbstractPoint3D, ::Plane) docstrings.

distance(p, plane) returns the scalar signed distance of the point from the plane (without abs), so the sign encodes which side of the plane the point lies on. Use abs(...) if you want the unsigned distance.

Coplanarity

See Library reference for both coplanar methods (point-vs-plane and vertex-collection vs plane).

coplanar(p, plane, threshold) returns true when the absolute distance from p to plane is at most threshold. The base method coplanar(vertices, threshold) is shared with Polygon3D and checks that all of vertices lie on a single plane.

Example

julia> using PhysicalMeshes
julia> using PhysicalParticles
julia> pl = Plane(PVector(0.0, 0.0, 0.0),
                  PVector(1.0, 0.0, 0.0),
                  PVector(0.0, 1.0, 0.0))Plane{Float64}(PVector{Float64}(0.0, 0.0, 0.0), PVector{Float64}(1.0, 0.0, 0.0), PVector{Float64}(0.0, 1.0, 0.0))
julia> PhysicalMeshes.normal(pl)PVector{Float64}(0.0, 0.0, 1.0)
julia> PhysicalMeshes.distance(PVector(0.0, 0.0, 3.0), pl)3.0
julia> PhysicalMeshes.distance(PVector(0.0, 0.0, -3.0), pl)3.0
julia> PhysicalMeshes.coplanar(PVector(0.5, 0.5, 0.0), pl, 1e-9)true
julia> PhysicalMeshes.coplanar(PVector(0.5, 0.5, 1.0), pl, 1e-9)false

Properties and conventions

  • Plane <: AbstractPlane3D <: AbstractPlane. There is currently no 2D plane primitive; the equivalent construct in 2D is a Line2D.
  • The normal returned by normal(...) has the same length units as the input points — i.e. for unitful input it is m, not m/m. This means that downstream dot products preserve the input's length² units (e.g. m^2 for area computations).
