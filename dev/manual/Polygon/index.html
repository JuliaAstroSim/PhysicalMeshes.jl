Polygon

Polygon2D and Polygon3D carry an Vector{PVector{...}} of vertices (>2 vertices, otherwise the constructor throws). Both support robust point-in-polygon checks via ray-casting, convex-polygon tests, and signed area / coplanarity tests.

Types

The polygon type hierarchy is AbstractGeometryType{T} > AbstractPolygon{T} > AbstractPolygon{2D,3D}{T} > Polygon{2D,3D}. See Library reference for the concrete structs.

Factory helpers

See Library reference for polygon_rect, polygon_regular.

Area, coplanarity, convexity

See Library reference for area, normal, isconvex, coplanar and the related shape predicates.

Point membership

See Library reference for the two is_inbound(::PVector, ::Polygon) methods.

For 2D inputs, is_inbound picks the convex (cross-product) algorithm when the polygon is convex and falls back to the standard ray-casting algorithm otherwise.

For 3D inputs, the point is first checked against the plane of the polygon (with a small unit(p.x)^2 * 1e-6 threshold) and then the 2D test is run on a local coordinate system constructed from the first two edges.

Compatibility shim

For backward compatibility with downstream code, both Polygon2D and Polygon3D expose a points alias for their canonical vertices field (through Base.getproperty and Base.propertynames).

Example

julia> using PhysicalMeshes
julia> using PhysicalParticles, Unitful
julia> # Rectangle
       rect = polygon_rect(4.0, 2.0)Polygon2D{PVector2D{Float64}}(PVector2D{Float64}[PVector2D{Float64}(2.0, 1.0), PVector2D{Float64}(2.0, -1.0), PVector2D{Float64}(-2.0, -1.0), PVector2D{Float64}(-2.0, 1.0)])
julia> PhysicalMeshes.area(rect)        # 8.08.0
julia> isconvex(rect)                   # truetrue
julia> PhysicalMeshes.is_inbound(PVector2D(0.0, 0.0), rect)   # truetrue
julia> PhysicalMeshes.is_inbound(PVector2D(5.0, 0.0), rect)   # falsefalse
julia> # Regular hex (circumradius = 1.0)
       hex = polygon_regular(6, 1.0)Polygon2D{PVector2D{Float64}}(PVector2D{Float64}[PVector2D{Float64}(1.0, 0.0), PVector2D{Float64}(0.5000000000000001, 0.8660254037844386), PVector2D{Float64}(-0.4999999999999998, 0.8660254037844387), PVector2D{Float64}(-1.0, 1.2246467991473532e-16), PVector2D{Float64}(-0.5000000000000004, -0.8660254037844385), PVector2D{Float64}(0.5000000000000001, -0.8660254037844386)])
julia> PhysicalMeshes.area(hex)         # ≈ 2.5982.598076211353316
julia> isconvex(hex)                    # truetrue
julia> PhysicalMeshes.is_inbound(PVector2D(0.0, 0.0), hex)   # truetrue
julia> PhysicalMeshes.is_inbound(PVector2D(2.0, 0.0), hex)   # falsefalse

Properties and conventions

  • The internal canonical field is vertices. Code written against the older .points alias still works through a Base.getproperty shim.
  • area(::Polygon2D) returns an unsigned value via the shoelace formula (decomposed as a fan of triangles anchored at the first vertex for numerical robustness).
  • normal(::Polygon2D) returns the unitless ẑ direction (and preserves the input units); normal(::Polygon3D) calls the normal(a, b, c) three-point version.
