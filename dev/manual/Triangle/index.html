Triangle

Triangle (3D, generic) and Triangle2D are the work-horses of the geometry layer: a triangle is enough topology to test orientation, circumcenter and incircle membership, and the 2D / 3D code paths share the same algorithmic families (Shewchuk-style robust predicates).

Types

The triangle type hierarchy is `AbstractGeometryType{T} > AbstractTriangle{T}

AbstractTriangle{2D,3D}{T} > Triangle{2D}`. See Library reference

for the concrete structs.

Arithmetic and basic vector quantities

See Library reference for the canonical docstrings of len, orient, orientation, area, centroid, circumcenter, incircle on the triangle family.

Example

julia> using PhysicalMeshes
julia> using PhysicalParticles, Unitful, UnitfulAstro
julia> t2 = Triangle2D(PVector2D(4.0, 3.0),
                       PVector2D(4.0, 0.0),
                       PVector2D(0.0, 3.0))Triangle2D{Float64}(PVector2D{Float64}(4.0, 3.0), PVector2D{Float64}(4.0, 0.0), PVector2D{Float64}(0.0, 3.0))
julia> orientation(t2)NegativelyOriented()
julia> len(t2)12.0
julia> PhysicalMeshes.area(t2)6.0
julia> centroid(t2)PVector2D{Float64}(2.6666666666666665, 2.0)
julia> circumcenter(t2)PVector2D{Float64}(2.0, 1.5)
julia> incircle(t2, PVector2D(3.0, 2.0))Interior()
julia> incircle(t2, PVector2D())OnEdge()
julia> incircle(t2, PVector2D(6.0, 0.0))Exterior()
julia> t3 = Triangle(PVector(0.0, 0.0, 0.0, u"m"),
                     PVector(3.0, 4.0, 0.0, u"m"),
                     PVector(3.0, 4.0, 12.0, u"m"))Triangle{Quantity{Float64, 𝐋, Unitful.FreeUnits{(m,), 𝐋, nothing}}}(PVector(0.0 m, 0.0 m, 0.0 m), PVector(3.0 m, 4.0 m, 0.0 m), PVector(3.0 m, 4.0 m, 12.0 m))
julia> len(t3)30.0 m
julia> PhysicalMeshes.area(t3)30.0 m^2
julia> centroid(t3)PVector(2.0 m, 2.6666666666666665 m, 4.0 m)
julia> circumcenter(t3)PVector(1.5 m, 2.0 m, 6.0 m)

Properties and conventions

  • The 3D Triangle carries the units of its vertices — len returns a length, area an area², centroid and circumcenter a PVector with the same length units.
  • orientation(::Triangle2D) returns one of the singletons PositivelyOriented(), NegativelyOriented() or UnOriented(). The same convention is used for Tetrahedron and other orientation-aware primitives.
  • incircle(::Triangle2D, p) reports whether p lies inside, on, or outside the triangle's circumcircle. The test is Shewchuk-style and is invariant under reflection of the input triangle.
